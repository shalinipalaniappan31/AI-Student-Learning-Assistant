# AI Student Learning Assistant

A beginner-friendly web application designed to help students learn basic programming and web development concepts through an interactive assistant, quizzes, and learning activity tracking.

## Features

- Interactive student learning assistant
- Question and answer system
- Chat history stored using MongoDB
- Clear chat history
- Quiz mode with 10 questions
- Automatic quiz scoring
- Correct answer review
- Student dashboard
- Quiz attempt tracking
- Latest quiz score tracking
- Responsive design for different screen sizes

## Technologies Used

- Python
- Flask
- HTML
- CSS
- MongoDB
- Jinja2
